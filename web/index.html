    03

    Connect via MCP

    Prefer an agent to drive this? The same jobs are exposed over the Model Context Protocol — point [CC], Cursor, or any MCP client at the endpoint below, and ask it to build the deck for you.

    Endpoint —
    Transport Streamable HTTP (stateless)
    Auth Same key as above, sent as X-API-Key or Authorization: Bearer.
    Flow create_deck_job → poll get_job → read the deck resource.
    Tools
    • create_deck_jobprompt + optional base64 files → job_id
    • get_jobstatus, usage, and recent events
    • list_jobsmost recent jobs
    • cancel_jobstop a running job
    Resource salindia://jobs/{job_id}/deck returns the finished .pptx once the job is completed.
